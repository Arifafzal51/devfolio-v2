# SkySight — Zero-Overhead Weather Visualizer

## Overview

SkySight is an ultra-fast, lightweight meteorological telemetry dashboard crafted with clean vanilla JavaScript, HTML5, and semantic CSS3. By eliminating bulky runtime frameworks, SkySight provides an instantaneous, zero-bloat forecast experience across desktop and mobile devices.

## Key Features

- **Instant Geolocation & Search:** Rapid geo-coordinate resolution and city search with defensive error handling.
- **Comprehensive Atmospheric Telemetry:** Real-time tracking of temperature, relative humidity, barometric pressure, UV levels, and wind vectors.
- **Dynamic Visual States:** Clean visual indicators and palette adjustments tailored to current meteorological conditions.
- **Zero Framework Overhead:** Pure native DOM manipulation ensuring sub-second initial load and minimal memory footprint.

## Tech Stack

- **Core Technologies:** HTML5, CSS3, JavaScript (ES6+)
- **API Integration:** OpenWeather REST API
- **Deployment:** GitHub Pages
